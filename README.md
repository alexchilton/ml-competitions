# ML Competitions

Open machine-learning competitions on every platform, by type and expected solution technique, plus my Kaggle board.
Refreshed daily from a local job (`kaggle-board/publish.sh`).

- **Competitions:** https://alexchilton.github.io/ml-competitions/
- **Kaggle board:** https://alexchilton.github.io/ml-competitions/board.html

Sources: mlcontests.com, the Kaggle, Zindi, CrunchDAO, Grand Challenge and Tianchi APIs, the DrivenData, DACON and DataSource.ai pages, and a hand-kept list.
Type and technique are labelled by a local Qwen model; they are best guesses, not verified.
